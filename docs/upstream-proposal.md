# Proposed contribution to FINOS Fluxnova

Offer a reusable benchmark harness and outcome-verification protocol, separate from the Fluxnova engine. It is not an adopted project standard.

The portable contribution contains BPMN workloads, synthetic services, original-input oracles, k6 arrivals, evidence contracts, reporting and tests. OCI provisioning, identity, secrets, private access, billing and database operations remain optional environment integration.

Agree location, ownership, supported versions, license/CLA and workload scope with maintainers first. A focused initial proposal is the offline harness and W02 oracle with golden/negative cases. Historical OCI measurements are supporting evidence, not engine code or production sizing guidance.

Proposed acceptance: a fresh-checkout demo, tests with documented optional integrations, a repeatable functional workload, a measured-study interface, sanitized evidence examples and no dependency on the author's private inventory. A later adapter can make isolated campaigns fully configurable without private operator helpers.

The [official contribution policy](https://github.com/finos/fluxnova-bpm-platform/blob/main/CONTRIBUTING.md) requires its review process and CLA before merge. This work has not been accepted, transferred or merged upstream. No upstream message or PR has been sent during this preparation.
