# Use the Fluxnova benchmark kit

The thesis is time to a **correct, authorized outcome**. Start with the [research brief](research-brief.md) or its [one-page PDF](assets/fluxnova-research-brief-20261028.pdf), then choose a path:

| Task | Maintained guide |
| --- | --- |
| Understand the workflow pictures | [How the benchmark works and nine diagrams](../README.md#how-a-measured-workflow-works) |
| Open a report and try sample data | [Getting started](getting-started.md) |
| Build and check a workflow | [Reproduction](reproduce.md) and [workloads](workloads.md) |
| Understand completed comparisons | [Pattern register](workload-completion.md) |
| Design a valid comparison | [Benchmark protocol](benchmark-protocol.md) and [metric definitions](measurement-contract.md) |
| Use OCI or another environment | [OCI setup](oci.md) and [portability](portability.md) |
| Inspect saved executions | [Browser automation](browser-automation.md) |
| Contribute or propose upstream adoption | [Contributing](../CONTRIBUTING.md) and [upstream proposal](upstream-proposal.md) |

Only the current handout, its source, maintained technical guides and selected final evidence summaries enter the release package. The explicit inventory is [release/public-files.json](../release/public-files.json). Unlisted drafts, historical decks, internal notes, private exports and presentation build intermediates remain excluded. A new file is not publishable just because it is named `final`.

The original private research archive retains earlier attempts and source history. The workflow studies and mixed follow-up are complete in their stated scopes; see the [pattern register](workload-completion.md). The public kit is an independent contribution candidate, not an adopted FINOS standard. Every publication follows the [release policy](public-release.md).
